# 0단계: 환경 점검

> 날짜: 2026-11-11 · 결과: ✅ 완료

## 무엇을, 왜
코드를 쓰기 전에 필요한 도구가 다 있는지 확인했다. 포토샵 플러그인은 일반 앱처럼 설치하지 않고
**UXP Developer Tool**로 개발 중인 폴더를 포토샵에 바로 올려(Load) 쓰기 때문에, 이 도구와 포토샵 개발자 모드가 꼭 필요하다.

## 확인한 환경

| 항목 | 값 |
|---|---|
| OS | Windows 11 Pro |
| Node.js | v24.14.0 (20 이상 권장 → 충분) |
| npm | 11.9.0 |
| git | 2.53.0 |
| Photoshop | **28.0.0** |
| UXP Developer Tool | 설치 완료 |
| 포토샵 개발자 모드 | 켬 (편집 > 환경 설정 > 플러그인 > 개발자 모드 활성화 → 재시작) |

## 만든 폴더 구조

```
D:\photoshop-agent
├─ mcp-server/    TypeScript MCP 서버 ("손의 관절")
├─ ps-plugin/     포토샵 UXP 플러그인 ("손가락")
├─ experiments/   단계별 검증 스크립트 (1단계에서 추가)
├─ output/        생성 이미지 저장 (저장은 이 안으로만 제한 예정)
├─ logs/          요청/결과 기록 (4단계)
├─ docs/          설명 문서 · 단계별 기록(docs/progress)
└─ .gitignore     node_modules, 빌드 결과, output/logs 내용은 git 제외
```

## 전체 구조에서의 역할
두뇌(Claude Desktop)와 연결되는 `mcp-server`, 포토샵 안에서 움직일 `ps-plugin`을 처음부터 분리해 두었다.
2단계(두뇌 직접 만들기)에서 두뇌만 바꾸고 이 두 부분은 그대로 재사용하기 위해서다.
