## 다시 실행하는 법 (요약)
1. `cd mcp-server && npm install && npm run build` (코드 바꾼 뒤엔 build)
2. Claude Desktop 설정: **설정 → 개발자 → [구성 편집]** 이 여는 파일
   (이 PC: `%LOCALAPPDATA%\Claude-Data\claude_pzs8sxrjxfjjc\claude_desktop_config.json`) 에 `mcpServers.photoshop-agent` 등록됨
3. Claude Desktop 완전 종료(트레이 → 종료) 후 재실행
4. UXP Developer Tool → PS Agent **Load** (manifest 바뀌면 Unload → Load, 코드만 바뀌면 Reload) → 패널 **연결** (현재 플러그인 **빌드 14**)
5. 포토샵 문서는 너무 많이 열지 않기 (8개일 때 "탭 공간 부족"으로 새 문서 실패)
6. 서버만 점검: `cd mcp-server && node scripts/selftest.mjs` (31개, 크레딧 0)

## 꼭 기억할 사실
- 생성 모델은 **표준** `clio3`(이미지) / `me_md`(채우기). Image 5 는 프리미엄(왕관) — 체험 소진 시 구매 창이 떠서 모든 명령이 `modal state` 로 막힌다.
- batchPlay 형식은 **녹화가 근거** (`experiments/00`, `02`). 포토샵 업데이트 후 생성이 안 되면 다시 녹화해 비교.
- Claude Desktop 은 서버를 **2개** 띄운다 → hub/relay 구조. `ps_status` 의 `serverRole` 로 확인.
- 생성은 `ps_prompt_guide(draft=…)` 로 **점검받은 문구만** 가능, `documentId` 필수.
- 지식 문서(`knowledge/*.md`)는 호출마다 새로 읽으므로 수정 후 재시작 불필요.
- 프롬프트 패턴 추가 수집: Claude Code 에서 "OO 프롬프트 패턴 모아 줘" → `.claude/skills/prompt-collector`
